# Console Calculator

A simple Java calculator that runs in the console. It takes two numbers and an operator, then prints the result.

## Features
- Addition, subtraction, multiplication and division
- Works with decimal numbers
- Prevents division by zero
- Shows a message for an invalid operator

## How to run
1. Open the project in NetBeans.
2. Run `Calculator.java`.
3. Enter the first number, an operator (`+ - * /`) and the second number.

## Example
```
Enter first number
10
Enter operator: '*, / , + , - '
+
Enter second number
5
10.0 + 5.0
result: 15.0
```
